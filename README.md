# MediCare Hospital Website

A responsive hospital-style website for the academic project **Intelligent Healthcare Appointment Scheduling Using Greedy and Genetic Algorithm Optimization**.

## Run locally
1. Extract the ZIP.
2. Open this folder in VS Code.
3. Open `index.html` with the VS Code Live Server extension, or open the file in a browser.

## Publish with GitHub Pages
1. Create a **public** GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for the Pages deployment and share `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Important
This is a fictional hospital website and an academic demonstration, not a real healthcare provider. Doctor names, contact details and content are illustrative. Appointment data is stored only in the visitor's browser using localStorage; it is not sent to a hospital or shared between visitors. Do not enter real patient information. The algorithm fitness score is an educational objective, not a clinical measure.

Doctor and hospital photos are loaded from Unsplash and Google Fonts is used for typography, so those assets require an internet connection.
